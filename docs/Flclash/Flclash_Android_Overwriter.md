## 📦 一、下载安装

* 🔗 下载地址：
  [Github Releases](https://github.com/chen08209/FlClash)

* 💻 支持平台：
  `Android` ｜ `Windows` ｜ `macOS` ｜ `Linux`

* 📌 操作说明：

  1. 根据系统选择对应安装包
  2. 下载并安装
  3. 启动软件，进入主界面



## ⚙️ 二、添加覆写（在线）
切换至 **工具** 页面 ，点击 `进阶配置 - 脚本 - 添加 - 通过URL导入`, 输入 `覆写配置链接`后，点击 **提交**
```
https://github.com/Seven1echo/Yaml/raw/refs/heads/main/Seven1_fallback_Rule-Set_Overwrite.js
```
![image](https://github.com/Seven1echo/Yaml/blob/main/docs/Flclash/pics/Flclash_Android_Overwriter/1.导入覆写.jpg)

>如拉取不成功，请配置代理后拉取


## 🧩 三、添加订阅
切换至 **配置** 页面 ，点击 `添加配置 - URL` ,输入`订阅名称`、`链接`，后，点击 **提交**
![image](https://github.com/Seven1echo/Yaml/blob/main/docs/Flclash/pics/Flclash_Android_Overwriter/2.添加订阅.jpg)



## ✔️ 四、勾选覆写
在 **配置** 页面，点击 `订阅链接名称 - 更多 - 覆写 - 脚本` ,选中刚下载的 `覆写配置` 即可 （也可点击预览，查看配置参数）
![image](https://github.com/Seven1echo/Yaml/blob/main/docs/Flclash/pics/Flclash_Android_Overwriter/3.勾选覆写.jpg)



## ▶️ 五、启动代理
切换至 **代理** 页面 ，按需选择策略组出口，然后切换至 **仪表盘** 页面，点击右下角 `开始` 按钮即可开启冲浪~
![image](https://github.com/Seven1echo/Yaml/blob/main/docs/Flclash/pics/Flclash_Android_Overwriter/4.策略启动.jpg)
